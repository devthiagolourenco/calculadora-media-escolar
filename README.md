## 📌 Sobre o Projeto
Este é um projeto desenvolvido em Python focado na aplicação prática de fundamentos de programação, como entrada e saída de dados (I/O), manipulação de variáveis, operadores aritméticos e controle de fluxo (estruturas condicionais). 

O objetivo do script é receber três notas escolares via terminal, calcular a média aritmética do aluno, arredondar o resultado para duas casas decimais e retornar a situação final (Aprovado, Recuperação ou Reprovado) com base no valor atingido.

## ⚙️ Funcionalidades
- [x] Captura interativa de três notas individuais via terminal (`input`).
- [x] Conversão de tipos de dados numéricos para ponto flutuante (`float`).
- [x] Cálculo automatizado da média aritmética utilizando operadores de adição e divisão.
- [x] Arredondamento numérico para duas casas decimais através da função nativa `round()`.
- [x] Exibição do resultado concatenando a *string* com o valor numérico convertido (`str`).
- [x] Avaliação da situação escolar utilizando estruturas condicionais múltiplas (`if`, `elif`, `else`) baseada na nota exigida (média 7 para aprovação e 5 para recuperação).

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.x
- **Ambiente:** Execução via Terminal/CLI
- **Bibliotecas:** Nenhuma biblioteca externa necessária (apenas recursos nativos da linguagem).

## 🚀 Como Executar o Projeto

### Pré-requisitos
Antes de começar, você precisará ter o [Python](https://www.python.org/downloads/) instalado na sua máquina.

### Passo a passo
1. Clone este repositório para o seu computador:
```bash
git clone [https://github.com/devthiagolourenco/calculadora-media-escolar.git](https://github.com/devthiagolourenco/calculadora-media-escolar.git)
```

2. Navegue até a pasta do projeto:
```bash
cd calculadora-media-escolar
```

3. Execute o script Python:
```bash
python calculadora_media_escolar.py
```
*(Dica: em alguns sistemas como Linux ou macOS, pode ser necessário usar o comando `python3` ou `python3 calculadora_media_escolar.py`)*
